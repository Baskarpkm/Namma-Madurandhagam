# Namma Madurandhagam — Feature Scope

## Public/User app
- One-time registration: Name, Mobile Number, Area/Village.
- Phone OTP verification planned with Firebase Phone Authentication.
- Persistent login until Logout.
- Home: status/stories, banners, categories, local updates.
- Directories: shops, workers/services, vehicles, jobs, offers, education/health/transport as content grows.
- Search and filters.
- Save and share.
- Notifications.
- User profile.
- Report content.
- Chat with Admin: text + images + videos; planned video limit 30 seconds.

## Status / Stories
- Admin uploads image/video stories.
- Video max 30 seconds.
- Auto-expire after 24 hours.

## Admin Dashboard
- Dashboard overview.
- Status management.
- Banner management.
- Category management.
- Shops / businesses.
- Events / News.
- Incidents / alerts.
- Jobs / offers / vehicles / worker listings.
- Users.
- Chat Inbox.
- Notifications.
- Media Library.
- Reports/moderation.
- Analytics.
- Settings.
- Audit logs.
- Suspend / ban / restore users.

## Commercial workflow
- Listing plans/pricing.
- Razorpay payment hooks.
- Review states: pending, approved, changes-required, rejected.
- Refund flow for rejected paid submissions.
- Renewal and expiry.
- Event end-date expiry.

## Media
- Cloudinary configuration hooks included.
- Store media URLs in MongoDB.

## Design
- Current final visual direction: clean blue-and-white mobile-first design.
- Rounded cards, consistent buttons, spacing, icon treatment and typography feel across public and admin surfaces.
